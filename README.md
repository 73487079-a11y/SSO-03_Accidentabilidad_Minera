# SSO-03: Sistema de Cálculo y Proyección de Tasas de Accidentabilidad

## 📊 Descripción
Aplicación en Python para cálculo y análisis de indicadores de seguridad:

- TIFAR
- TIPAR
- TISSAR
- IA
- FAR
- DMI

Incluye simulación Monte Carlo, análisis OLS y exportación a PDF/Excel.

## ⚙️ Instalación
pip install -r requirements.txt

## ▶️ Ejecución
python app.py
